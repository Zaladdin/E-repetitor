## Разработка и проверка

- Сначала изучить существующие файлы и определить стек; установка навыков не
  означает выбор React, Next.js, shadcn или создание приложения.
- Использовать подходящие навыки уже установленного ECC: `frontend-patterns`,
  `react-patterns`, `frontend-a11y`, `api-design`, `backend-patterns`, `e2e-testing`.
  Исходный каталог: `C:/Users/Zaladdin/.codex/vendor/ecc/skills/`.
- Применять соразмерное планирование, регрессионные проверки, профильный обзор
  и проверку результата. Не обещать непроверенные проценты покрытия.
- Для браузера использовать доступные инструменты Codex и их инструкции.
  Упоминания `WebFetch` в навыках трактовать как доступный инструмент чтения веба.
- Использовать PowerShell. Примеры запуска UI/UX Pro Max адаптированы в его SKILL.md
  под локальный Python из комплекта Codex; дополнительные пакеты не нужны.
- Сохранять выбранную модель, установленные плагины и пользовательские изменения.
  Установка навыков не разрешает hooks, сервисы, деплой, commit/push или операции
  с production-данными.

Источники и точные версии: `docs/skills.md`.
