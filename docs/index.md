# Обучение ребёнка в одном кабинете

**E-repetitor** — проект платформы для независимых репетиторов, учеников и родителей.
Преподаватель ведёт занятия, создаёт тесты и учитывает оплаты. Родитель видит
предметы ребёнка и опубликованные результаты всех его преподавателей.

Разработка ведётся по ТЗ v1.1. Локально доступны регистрация, подтверждение почты,
сессии, постоянные профили и предметы с хранением в PostgreSQL. Подключения трёх
кабинетов по Student ID также сохраняются на сервере с подтверждением учеником.
Новых учеников преподаватель может пригласить по одноразовой ссылке из письма.
Добавлены индивидуальное расписание, переносы, отмены и посещаемость.
Работают конструктор тестов, назначения, прохождение с сохранением ответов,
проверка и публикация результатов для ученика и родителя.
Есть ручной журнал оплаты: преподаватель ставит отметку, семья видит статус.
Оплата происходит вне платформы.
Добавлен общий обзор кабинета: ближайшие занятия, тесты, опубликованные результаты,
посещаемость и отметки оплаты. Родитель может выбрать ребёнка или видеть всех детей.
Работает центр уведомлений о занятиях и тестах с настройками каналов.
Добавлен базовый кабинет администратора: пользователи, статусы доступа и аудит.
Проведена локальная подготовка пилота: общий сценарий ролей и пробное восстановление базы.
На этом сайте опубликованы документы проекта; серверное приложение запускается отдельно.

## Как будет работать платформа

| Участник | Возможности |
| --- | --- |
| Преподаватель | Своя учётная запись, ученики, расписание, конструктор тестов, результаты и оплаты |
| Ученик | Единый постоянный ID, подключение к разным преподавателям, задания и прохождение тестов |
| Родитель | Все предметы ребёнка, посещаемость, результаты и статусы оплаты в одном кабинете |

Ученик регистрируется один раз и использует свой ID у разных репетиторов.
Родитель отправляет запрос, ученик подтверждает связь, после чего родитель
получает общий обзор обучения ребёнка.
