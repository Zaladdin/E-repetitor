# Обучение ребёнка в одном кабинете

**E-repetitor** — проект платформы для независимых репетиторов, учеников и родителей.
Преподаватель ведёт занятия, создаёт тесты и учитывает оплаты. Родитель видит
предметы ребёнка и опубликованные результаты всех его преподавателей.

Сейчас проект находится на этапе проектирования. На этом сайте опубликованы
концепция и требования; рабочие кабинеты и регистрация появятся после разработки приложения.

## Как будет работать платформа

| Участник | Возможности |
| --- | --- |
| Преподаватель | Своя учётная запись, ученики, расписание, конструктор тестов, результаты и оплаты |
| Ученик | Единый постоянный ID, подключение к разным преподавателям, задания и прохождение тестов |
| Родитель | Все предметы ребёнка, посещаемость, результаты и статусы оплаты в одном кабинете |

Ученик регистрируется один раз и использует свой ID у разных репетиторов.
Родитель подтверждает связь с ребёнком и получает общий обзор его обучения.
