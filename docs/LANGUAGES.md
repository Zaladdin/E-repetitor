# Языки интерфейса

Приложение и демо доступны на русском, азербайджанском и английском языках.
Переключатель находится в шапке и доступен до входа в аккаунт. Выбор сохраняется
в браузере; при переходе между страницами и перезагрузке используется выбранный
язык. Если хранилище браузера недоступно, переключение действует в текущем окне.

Переключение обновляет интерфейс без перезагрузки и сохраняет содержимое открытых
форм. Переводятся навигация, подписи, формы, статусы, сообщения об ошибках,
группы, расписание, тесты, оплаты, пакеты и администрирование. Даты и числа
форматируются через `Intl` для `ru-RU`, `az-AZ` и `en-GB`. Язык документа и
заголовок вкладки также обновляются.

Имена, предметы, названия групп, вопросы тестов, ответы и другие пользовательские
данные не переводятся. Для уведомлений переводятся заголовок и системная часть;
имена и предметы сохраняются. Содержимое технической документации и письма
локального тестового сервера остаются на исходном языке.

## Поддержка переводов

- `src/lib/i18n.ts` — языки, хранилище выбора, перевод и подстановка параметров.
- `src/components/locale-provider.tsx` — React-контекст и переключатель.
- `src/lib/i18n/*.ts` — словари по разделам. Ключ — исходная русская строка,
  значение — пара `[English, Azərbaycan]`.
- В компонентах используется `useI18n().t`, а в обычных функциях — `translate`.
  Постоянные статусы хранят исходные подписи и переводятся при отображении.
- Динамические значения передаются параметрами: `t('Непрочитанных: {count}',
  { count })`. Пользовательский текст не передаётся как ключ перевода.

Статический экспорт сохраняет существующие адреса страниц. Первоначальный HTML
использует русский язык; после загрузки восстанавливается выбор браузера.
Смена языка не изменяет роли, API-параметры, часовой пояс занятий или данные БД.

## Проверки

Тесты проверяют полноту словарей для вызовов перевода, сохранение параметров,
отрисовку интерфейса, локальные форматы, сохранение выбора и отказ хранилища.
Отдельно проверяется сохранность имён, названий и системных API-значений.

- Frontend: `npm test` — 183 из 183 тестов прошли.

  сохранение открытого черновика при смене языка и адаптивность при ширине 375 px.
