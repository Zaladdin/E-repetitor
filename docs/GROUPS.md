# Группы учеников и еженедельное расписание

Преподаватель открывает «Группы», выбирает предмет и добавляет учеников из
подтверждённых активных подключений к этому предмету. У группы есть название,
состав и часовой пояс. В одном аккаунте можно создать несколько групп.

Для каждого интервала выбираются дни недели и время начала/окончания.
Например: понедельник и среда 16:00–17:30, пятница 15:00–16:00.
Состав и расписание можно редактировать. Архивация прекращает показ группы
в текущем расписании, сохраняя запись группы на сервере.

В «Расписании» выбранной недели отображаются повторяющиеся занятия группы.
Преподаватель видит свои группы, ученик — свои занятия, родитель — занятия
детей с активной подтверждённой связью. Список других участников семье не
передаётся. Время пересчитывается из часового пояса группы в пояс устройства.

Это еженедельный план: он не создаёт индивидуальные записи посещаемости,
списания пакетов или отметки оплаты. Изменение шаблона применяется к его
отображению; отдельные отмены и история посещаемости групповых встреч пока
не предусмотрены. Существующие индивидуальные занятия работают отдельно.

## API и данные

- `GET/POST /api/v1/groups` — список / создание групп преподавателя.
- `GET /api/v1/groups/candidates?subjectId=…` — доступные ученики предмета.
- `PATCH /api/v1/groups/:id` — название, состав и расписание с проверкой версии.
- `POST /api/v1/groups/:id/archive` — архивация с проверкой версии.
- `GET /api/v1/groups/schedule?role=…&from=…&to=…` — занятия за период до 93 дней.

Создание использует `requestId` для безопасного повтора запроса. Дни недели:
1 — понедельник, 7 — воскресенье. Время: `HH:mm`; окончание позже начала,
длительность не более 8 часов. До 50 учеников и 14 интервалов в группе.
Пересекающиеся интервалы внутри одной группы отклоняются.

Аддитивная миграция `012_student_groups.sql` добавляет таблицы групп, участников
и интервалов. Новые записи хранятся в PostgreSQL. Откат приложения не требует
удаления этих таблиц. Локальный запуск требует применения миграции к локальной
базе перед использованием новых страниц.

## Локальная проверка — 24 сентября 2026

- Frontend: 166 тестов, включая API-контракт групп и преобразование/проверку
  недельных интервалов. ESLint без ошибок и предупреждений.
- PostgreSQL: 53 проверки в наборах connections, groups, lessons и packages;
  после исправления проверки вложенных массивов повторно прошли 11 тестов groups.
- Сборка сайта и API для единого локального адреса прошла успешно.
- В браузере проверены создание группы из активного ученика, редактирование
  времени, сохранение после перезагрузки, показ у преподавателя, ученика и
  родителя, повторение на следующей неделе и архивация тестовой группы.
- При ширине 1920 px логотип, меню и выход имеют общий вертикальный центр.
  При ширине 390 px страница и диалог не выходят за доступную ширину.
- Проведён профильный обзор React/TypeScript и схемы БД; найденная ошибка
  валидации некорректной структуры интервалов исправлена и покрыта регрессией.

Перед применением миграции к локальной базе создана резервная копия через
`pg_dump`. Интеграционные тесты запускались в отдельной базе с суффиксом `_test`.
