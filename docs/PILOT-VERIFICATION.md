# Проверка локального пилота — 23 сентября 2026

Windows, Node.js 22, локальные PostgreSQL и Mailpit, встроенный браузер Codex.
Это проверка локальной версии на вымышленных участниках. Внешнее размещение,
настоящие письма, платёжные операции и приглашение реальных семей не выполнялись.

## Сквозной API-сценарий

Добавлен `api/test/pilot.test.ts`. Он запускает настоящий HTTP API с PostgreSQL
и проходит регистрацию, подтверждение почты и вход преподавателя, ученика и родителя.
Письма регистрации перехватываются в памяти. Второстепенные участники созданы
тестовыми fixtures с настоящими серверными сессиями. Сценарий дважды прошёл отдельно.

Далее через API выполнены: подключения к математике и физике по одному Student ID,
подтверждения учеником, родительская связь, занятия, посещаемость, два смешанных
теста, ответы, ручная проверка, публикация, ручные оплаты и итоговая сводка семьи.
Для проверки посещаемости время одного вымышленного урока перенесено в прошлое
через SQL; остальные доменные изменения проходят через рабочие API.

Проверены чужие UUID, запрет преподавателю управлять чужим предметом, запрет ученику
и родителю изменять оплаты, закрытые неопубликованные результаты, скрытые ответы
и ключи, а также отсутствие данных у неподтверждённого родителя. После отзыва связи
обзор, занятия, платежи и результаты немедленно закрываются родителю; собственная
история ученика и преподавателей сохраняется.

Перед миграциями и очисткой новый сценарий требует непроизводственную локальную
PostgreSQL с отдельным именем `_test`, без query/fragment-переопределений URI.

Финальный `npm.cmd run api:test`: **147/147 тестов, 10 наборов**, без ошибок,
пропусков и отмен; свежая TypeScript-сборка успешна. Время полного набора —
7 минут 42 секунды. Финальный `npm.cmd run lint` завершился без предупреждений.
Проверка ссылок семи затронутых документов и `git diff --check` также прошли.

## Браузерный сценарий

Подготовлены четыре отдельных вымышленных аккаунта: два преподавателя, ученик,
родитель. Аккаунты созданы локальной fixture; предметы, подтверждения связей,
расписание и назначения подготовлены через API. Ниже — действия именно в браузере:

1. Ученик вошёл в кабинет и увидел два предмета, один Student ID, два занятия,
   неоплаченные записи и опубликованный пример по физике.
2. Начал математический тест, выбрал ответ `4`, написал объяснение чётности,
   сохранил ответы и сдал работу. Статус стал «На проверке», итог ещё закрыт.
3. Преподаватель математики вошёл отдельно, увидел только свою работу, оценил
   письменный ответ на 3 балла, сохранил проверку и опубликовал результат 5/5.
4. Этот преподаватель поставил «Оплачено» для своей записи на 80 AZN.
   Интерфейс подтвердил сохранение; деньги на сайте не переводились.
5. Родитель вошёл и увидел математику и физику, результаты 5/5 и 2/2,
   общий комментарий, два занятия, одну оплаченную и одну неоплаченную запись.
   В его разделах нет редактирования оценок/оплат и подробных ответов ученика.
6. Мобильный обзор визуально проверен: `clientWidth=341`, `scrollWidth=341`,
   горизонтальной прокрутки нет. Ограничение viewport снято.
7. Проверенные console warn/error пусты. Оставлен родительский кабинет
   `http://127.0.0.1:3000/account/` для просмотра вымышленных данных.

Инструмент проверки checkbox сообщил о замене элемента после сохранения оплаты.
Действие не повторяли: отдельное чтение показало «Оплата отмечена», статус «Оплачено»
и новое время, затем результат подтвердился в кабинете родителя.

## Резервная копия и восстановление

Добавлены `api/src/backup.ts`, `backup.cli.ts`, команда `backup:verify` и шесть
проверок её ограничений. Независимый ECC code/TypeScript review одобрил реализацию.
По обзору в сравнение схемы дополнительно включены функции, триггеры и enum-типы.

Первый запуск успешно создал архив, но остановился на создании базы: у роли
приложения нет CREATEDB. После этого инструмент дополнен отдельной операторской
конфигурацией и ранней проверкой права. Права приложения не расширялись.
Операторский URI ограничен тем же локальным сервером и портом, базой `postgres`.

Успешное восстановление:

| Показатель | Результат |
| --- | --- |
| Источник | Локальная `e_repetitor`, согласованный read-only снимок |
| Назначение | `e_repetitor_restore_20260922211009_c51e2dd6f726`, новая база |
| Таблицы / строки | 31 / 258; количества и хеши всех таблиц совпали |
| Миграции | 9, совпали с файлами checkout |
| Схема | Колонки, ограничения, индексы, функции, триггеры и enum-типы совпали |
| Время pg_restore | 1,545 секунды |
| Вся процедура | 6,647 секунды |
| Артефакты | `.local/backups/pilot-mImI8h/`, игнорируются Git |

ACL папки проверен: только текущий Windows-пользователь и SYSTEM, без наследуемых
разрешений. Старые базы не удалялись и не перезаписывались. Частичный архив первого
запуска также сохранён в приватной папке; базы назначения тогда создано не было.

На восстановленной базе временно поднят отдельный API на случайном loopback-порту
с выключенным почтовым работником. Вход QA-родителя и обзор вернули 200; видны два
предмета и один результат, опубликованный к моменту снимка. Второй результат и
оплата были изменены в рабочей базе позже — в более раннюю копию они не входят.
Временный API остановлен. Проверочный вход добавил сессию и аудит только в копию
после сравнения; сам архив остался неизменным.

## Локальный замер чтения

После завершения серверных тестов выполнено по 10 последовательных чтений
родительского API; по одному предварительному запросу каждого типа исключено
из измерения. Учитывается HTTP-ответ и чтение JSON на том же компьютере.

| Маршрут | Медиана | Максимум |
| --- | --- | --- |
| Обзор родителя | 20,4 мс | 21,4 мс |
| Ручные оплаты | 15,2 мс | 21,3 мс |
| Тесты и результаты | 35,7 мс | 385,9 мс |

Все запросы вернули 200. Это исходный замер на маленькой базе с одним клиентом,
не нагрузочное испытание и не обещание времени ответа для внешнего пилота.

## Обзор прав и границы

Независимо просмотрены отрицательные сценарии всех текущих семейств маршрутов:
аккаунты/предметы, подключения, приглашения, занятия, тесты/попытки, оплаты,
сводка, уведомления и администрирование. Существенного непроверенного перехода
доступа в текущем объёме не найдено. Это оценка сценариев, а не утверждение
о полном переборе всех ролей для каждого HTTP-метода.

Процент покрытия, нагрузочная ёмкость и полный WCAG-аудит не измерялись.
Неизменённый frontend ранее прошёл 101 тест, проверку типов и production-сборку
на этапе администратора. Домашние задания, количественные пакеты, списания,
файлы и внешняя инфраструктура остаются за пределами текущего прогона.

Commit, push, deployment и расписание автоматических backup этим этапом не выполнялись.
