# Локальная приёмка — 23 сентября 2026

Проверка выполнена во встроенном браузере Codex на
`http://127.0.0.1:3100/account/`, с локальными PostgreSQL и Mailpit.
Использованы только вымышленные аккаунты прежнего пилота: преподаватели
математики и физики, ученик и подтверждённый родитель. Письма в интернет,
платёжные операции и внешнее размещение не выполнялись.

## Найденные и исправленные проблемы

1. В форме нового пакета кнопка «Обновить учеников» сбрасывала выбранное обучение,
   сохраняя остальные поля. Проблема воспроизведена в браузере. Выбор теперь
   хранится в состоянии формы. Перед отправкой проверяется, что запись всё ещё
   входит в загруженные активные обучения; отсутствие записи объясняется отдельно.
2. В расписании оставалась устаревшая подсказка о будущем подключении расчётов.
   Теперь она объясняет явное списание преподавателем и ведёт к пакетам занятий.
3. История пакета показывала «−1 занятий». Для изменений остатка применяется
   существующее русское склонение: «−1 занятие», «+8 занятий».

## Выполненные браузерные сценарии

- Родитель видит математику и физику, опубликованные результаты 5/5 и 2/2,
  оплаченные и неоплаченные записи. Пакет математики показывает 7 из 8 занятий
  и оплату 200 AZN. Приватные причины исправлений и кнопки изменения отсутствуют.
- История открывается и закрывается; фокус возвращается на кнопку вызова.
- Закреплённое меню переводит фокус в раздел, обновляет адрес и активный пункт.
  Проверены обзор, расписание, тесты, пакеты, подключения и оплата. Кнопка браузера
  «Назад» возвращает раздел. Неподанный черновик Student ID сохраняется при этих
  переходах; после проверки он очищен.
- Выход родителя и вход преподавателя завершены через интерфейс.
- Попытка закрыть изменённую форму пакета запрашивает подтверждение.
  «Продолжить заполнение» сохраняет название, количество и сумму.
- На новой сборке повторён сценарий обновления учеников: выбранное обучение
  сохранилось. Некорректная сумма `abc` показывает ошибку с переводом фокуса;
  после исправления создан пакет «Приёмка · 3 занятия» за 75 AZN.
- Ручная галочка оплаты обновила журнал и пакет без перезагрузки страницы.
  Возврат занятия в прежнем пакете увеличил остаток 7 → 8, новое списание
  вернуло его к 7. Уже списанного урока нет в выборе, кнопка отправки недоступна.
  Изменения сохранили историю и не изменили оплату.
- Новый тестовый пакет закрыт с причиной. Он сохраняет 3 из 3 занятий, оплату
  и историю, а кнопки списания и повторного закрытия больше не показываются.
- После входа ученик видит постоянный Student ID, двух преподавателей,
  результаты 5/5 и 2/2 и оба пакета. Ученик и родитель видят одинаковые остатки,
  оплату и шесть движений прежнего пакета; приватные причины преподавателя
  отсутствуют. В журнале оплаты ученика нет изменяемых галочек.
- Прямая ссылка на уведомления раскрывает раздел, в том числе после обновления
  страницы с восстановлением сессии.
- При ширине 375 px карточка пакета перестраивается в одну колонку, меню
  прокручивается внутри своей полосы. Горизонтального переполнения документа нет.
  Enter на ссылке открывает раздел; следующий Tab переводит фокус на «Обновить»
  с видимым выделением. При ширине 768 px переполнения документа также нет,
  целевой раздел располагается ниже закреплённого меню.
- Мобильное окно истории помещается по ширине и прокручивает длинное содержимое
  внутри себя. Временные размеры браузера сброшены. Приложение оставлено
  работающим с обзором вымышленного родителя.

## Проверки исправлений

- `npm test -- src/lib/account-navigation.test.ts src/lib/account-packages-api.test.ts src/lib/account-packages-ui.test.ts`
  — **10/10 тестов, 3 файла**.
- `npm run lint` — успешно.
- `npm run local:build` — успешно: статический экспорт интерфейса, проверка
  TypeScript и сборка API. Обновлённая сборка запущена через `npm run local:start`.
- Независимые ECC React и code/TypeScript review трёх исправленных компонентов
  завершены без существенных замечаний. Исправление выбора ученика дополнительно
  подтверждено в браузере после сборки.
- В журнале браузера по завершении сценариев нет сообщений `warn`/`error`.

В локальной базе оставлены вымышленные записи приёмки: закрытый оплаченный
пакет 3 занятия / 75 AZN и два новых движения прежнего пакета. Итог старого
пакета — 7 из 8, оплачено. Сводка семьи теперь показывает три оплаченные записи
и одну без отметки. Учётные данные и локальные фикстуры не добавлены в Git.

## Границы проверки

Это ручная локальная приёмка выбранных сценариев, а не полная проверка всех
возможностей приложения или сертификация доступности. Автоматический аудит
доступности, измерения Core Web Vitals и сравнение со снимками эталонного дизайна
в этот этап не входят. Проверка на настоящем телефоне и полный обход фокуса
всех модальных окон остаются отдельными задачами.
Полные серверные результаты предыдущего этапа приведены в
[отчёте пакетов](PACKAGES-VERIFICATION.html); неизменённый API повторно не тестировался.
