# Дизайн первого этапа

Рабочий концепт создан встроенным Image Gen для интерактивного прототипа по ТЗ v1.1.
Файл: [teacher-workspace-concept.png](teacher-workspace-concept.png), 1536 × 1024.
Это исходная визуальная спецификация реализации, а не утверждённый пользователем
финальный дизайн. Интерфейс собран из HTML/React, изображение не используется вместо UI.

## Система оформления

- Белый фон `#ffffff`, тёмная боковая панель `#172d38`, основной текст `#101b29`.
- Акцент `#245e4c`, выделение `#bce4cf`, светлая информация `#e4f3ec`.
- Нейтральные подписи `#526477`, разделители `#dce4e8`, предупреждения `#fff1c9`.
- Системный sans-serif: Arial/Helvetica; заголовок 54 px, секции 26 px,
  основной текст и элементы управления 16 px, подписи 14 px.
- Боковая панель 256 px, отступ основного контента 38 px. Метрики разделены линиями.
- Расписание — список; ученики — таблица; предметы — компактные строки.
- Иконки Lucide: CalendarDays, UsersRound, BookOpen, MessageSquare, Plus,
  ArrowRight, ChevronRight, Info, X, Menu. Контур 1.75–2 px.
- Навигация: Сегодня, Ученики, Предметы, Запросы. Другие роли используют эту же систему.
- На телефоне панель заменяется раскрываемым меню, секции идут в одну колонку,
  таблица имеет локальный горизонтальный скролл, формы сохраняют видимые подписи.

## Текст и взаимодействия

Первый экран сохраняет заголовок «Сегодня», дату «Вторник, 22 сентября», действие
«Подключить ученика», блоки «План на сегодня», «Ваши предметы» и «Ученики».
Демонстрационная дата фиксирована; сроки запросов считаются от реального времени.
Показатели вычисляются по демонстрационным данным. Запланированные занятия —
иллюстрация будущего модуля расписания, а не реализованное создание уроков.

Нужные для сценария продолжения: список/поиск учеников, создание предмета,
форма подключения по ID, входящие запросы ученика, выбор ребёнка у родителя,
подтверждение отзыва связи и сброса демо. Все используют общие поля, кнопки,
строки и нативные модальные диалоги. Переключение демо-профилей не является входом.

Осознанные уточнения концепта: третье демонстрационное занятие относится к
подтверждённой математике; у ожидающего запроса показывается ID вместо имени.
Весь демонстрационный набор условный. Прототип предназначен для оценки сценариев,
реальные данные детей вводить в него не следует.

## Brief генерации

Полный рабочий экран E-repetitor на русском языке, 1536 × 1024; тёмная боковая
панель и белая рабочая область, мятный акцент, просторная типографика. Кабинет
Анны Смирновой: два активных ученика, три занятия-примера и один запрос.
Показать расписание, свои предметы, объяснение Student ID и таблицу учеников.
Никаких иллюстраций, маркетинговых блоков, графиков или интерфейса в виде картинки.
