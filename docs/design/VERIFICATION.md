# Проверка прототипа от 22 сентября 2026

Объём: первый этап ТЗ v1.1 — локальная демонстрация идентичности и подключений.
Авторизация и защита реального API не входят в этот прототип.
После добавления аккаунтов прототип доступен по `/demo/`. Ниже сохранён отчёт
первого этапа; актуальная серверная проверка описана в `../ACCOUNTS-VERIFICATION.md`.

## Автоматические проверки

- `npm run lint` — успешно.
- `npm run typecheck` — успешно.
- `npm test` — 18 тестов в двух файлах успешно.
- `npm run build` — успешно, статический экспорт в `out/`.
- React-, TypeScript- и общий обзор выполнены; существенных открытых замечаний нет.

Проверены чужой Subject, изоляция преподавателей, невозможность подтвердить чужую
связь, закрытый доступ родителя до подтверждения, несколько детей/родителей,
агрегация второго преподавателя, отзыв, повторные запросы, TTL и переходы статусов.
Четыре теста восстановления проверяют пригодное состояние, повреждённый/неверный
формат, пустой набор и отключённую демонстрационную учётную запись.

## Проверка в браузере

Использован Codex In-app Browser; fallback-браузер не потребовался.
Проверены обычное окно, CSS viewport 1536 × 1024 и телефон 390 × 844.
Размеры подтверждены через DOM; для компенсации масштаба браузера viewport
задавался 1690 × 1126 и 429 × 928 соответственно. В конце override снят.
На телефоне нет горизонтального переполнения страницы; таблица имеет свой скролл.

Пройден сценарий Мурад → запрос по ID Али → принятие Али → два предмета у Лейлы.
Анна продолжает видеть только свои связи. Пройден Нигяр → запрос Софии → отсутствие
данных до подтверждения → подтверждение Софией → математика в кабинете Нигяр.
На телефоне создан предмет «Геометрия», проверено закрытие меню и фокус на основном
контенте. После перезагрузки ранее созданные связи сохраняются. По завершении
демонстрация возвращена к исходному набору. Ошибок/предупреждений в консоли при
финальной проверке не обнаружено.
