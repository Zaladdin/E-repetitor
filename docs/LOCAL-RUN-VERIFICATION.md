# Проверка единого локального запуска — 23 сентября 2026

Проверено на Windows, Node.js 22, существующих локальных PostgreSQL и Mailpit.
Облачное размещение и внешняя отправка писем не выполнялись.

## Автоматические проверки

- `npm run local:build` завершил статический экспорт Next.js в `.local/web` и
  TypeScript-сборку API. Проверены страницы `/`, `/account/`, `/demo/`.
- `npm run lint` и `npm run typecheck` завершились успешно.
- Тесты launcher: **5/5** — локальные адреса, запрет удалённых конфигураций,
  IPv6, относительный API и распознавание локальной сборки.
- HTTP-тесты статической раздачи: **5/5** — страницы, скрипты, Flight-данные,
  HEAD/redirect, CSP с хэшами, сохранение API-маршрутов, настоящие 404,
  запрет dotfiles/traversal и отказ при неполной сборке.
- Регрессия аккаунтов PostgreSQL: **14/14** — регистрация, почта, сессии,
  CSRF, изоляция, сброс пароля и ограничения запросов.
- Независимый ECC code/TypeScript/security review: существенных замечаний нет.

В первом запуске проверки аккаунтов PostgreSQL ещё не работал: 14 тестов были
отменены из-за `ECONNREFUSED`. После штатного запуска существующей инфраструктуры
и автоматического восстановления PostgreSQL набор повторён успешно. Исходная
рабочая база не пересоздавалась; тесты использовали отдельную `e_repetitor_test`.
Полные неизменённые наборы других модулей на этом этапе повторно не запускались.

## Проверка настоящей сборки

`npm run local:start` запустил один NestJS-процесс на `127.0.0.1:3100`.
Встроенный браузер загрузил `/account/` и восстановил существующую тестовую
сессию родителя. Затем выполнены выход, повторный вход и переход к оплатам;
после перезагрузки страницы сессия сохранилась.

Родитель видит математику и физику, результаты 5/5 и 2/2, одну оплаченную и
одну неоплаченную запись. Это ранее подготовленные вымышленные данные пилота.
Стили, скрипты и гидратация загрузились; console warn/error пусты.

Для вымышленного аккаунта запрошено письмо восстановления. Mailpit получил его
со ссылкой на `http://127.0.0.1:3100/account/`. Пароль не изменялся, сообщение
не отправлялось в интернет. Одноразовый токен в документацию не включён.

Приложение оставлено работающим для просмотра. Миграции рабочей базы,
изменения полномочий, commit/push и deployment на этом этапе не выполнялись.
