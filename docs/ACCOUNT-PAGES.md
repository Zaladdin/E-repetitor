# Страницы кабинета

Кабинет использует отдельные статически экспортируемые страницы Next.js:

- `/account/overview/` — обзор;
- `/account/lessons/` — расписание;
- `/account/groups/` — группы учеников и еженедельное расписание, для преподавателя;
- `/account/tests/` — тесты и результаты;
- `/account/payments/` — оплата;
- `/account/packages/` — пакеты занятий;
- `/account/connections/` — ученики и предметы / подключения;
- `/account/notifications/` — уведомления;
- `/account/settings/` — аккаунт;
- `/account/admin/` — администрирование, только при наличии серверного права.

Общая шапка закреплена сверху: на широком экране логотип, навигация и выход
выровнены в одну строку. На узких экранах логотип и выход остаются сверху,
а полоса ссылок прокручивается во второй строке.
Активная страница обозначена `aria-current="page"`. Переключение ролей доступно
в настройках для аккаунтов с несколькими ролями.

Общий layout сохраняет сессию и выбранную роль при переходах. Компоненты данных
монтируются только для открытой страницы; счётчик уведомлений обновляется также
на остальных страницах. Незавершённые формы внутри страницы при уходе с неё
размонтируются. Прямые адреса поддерживают обновление и открытие в новой вкладке.
Старые ссылки `#account-…-section` переводят на соответствующую страницу.

Локальная сборка и запуск описаны в [LOCAL-RUN.md](LOCAL-RUN.md).
